# 📋 TaskFlow — Collaborative Project Management Tool

> A full-stack real-time project board developed for **CodeAlpha Task 3**.

---

## 🌟 Key Features
* 📁 **Group Projects:** Create and organize custom project workspaces.
* 📌 **Kanban Boards:** Move task cards across `To Do`, `In Progress`, and `Done` columns.
* 👤 **Task Assignment:** Assign specific tasks to project members.
* 💬 **Task Communication:** Post comments and maintain task discussion threads.
* ⚡ **Real-Time WebSockets (Bonus):** Live Kanban board synchronization using **Socket.io**.

---

## 🛠️ Stack
* **Frontend:** HTML5, CSS3, JavaScript (ES6+), FontAwesome
* **Backend:** Node.js, Express.js, Socket.io, MongoDB, Mongoose
